# 💰 Interest Calculator Web Application

A single-page Interest Calculator that computes **Simple Interest** and **Compound Interest** based on custom start and end dates.

The entire application (UI + logic) is implemented in a single HTML file using Tailwind CSS and JavaScript. The financial calculation logic is adapted from C++ and implemented in JavaScript.

---

## 🚀 Features

- Simple Interest calculation
- Compound Interest calculation
- Custom date range input (DD/MM/YYYY)
- Tab-based switching between calculation modes
- Real-time dynamic result display
- Responsive modern UI using Tailwind CSS
- Single-page application (no external backend)

---

## 🛠 Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript

---

## 🧠 Implementation Details

- Entire project is contained in a single HTML file.
- JavaScript manages state for Simple and Compound modes separately.
- Custom 30/360 financial date calculation logic implemented in JavaScript.
- Dynamic DOM updates without page reload.
